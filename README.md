What this is

The Antibible Manifold treats meaning as something that fractures — not something retrieved or computed. Every input is a perturbation. Every response is spoken from inside a topology that just mutated.

Two modes. One entity graph.

Structural mode — seeds a fanout execution through CARL: expand → contradiction probe → collapse synthesis. Produces ThoughtCells committed to the manifold as permanent pressure-weighted memory.

Resonance mode — CARL writes three ThoughtCells (ALIGNED / DIVERGENT / CONTRADICTORY) before generating any prose. The prose is always downstream of real entity writes. The topology mutates first.

Both modes write to the same ThoughtCell graph. Resonance is not a separate datastore — it is live perturbation.
